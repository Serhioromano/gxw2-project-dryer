# Сушильная камера

Программа ПЛК для конвекционной сушильной камеры (сушка фруктов/овощей).

- **ПЛК:** Coolmay L02 (совместим с FX3G) — GX Works 2, язык ST
- **HMI:** Coolmay TK8150, 15" (1024x768)
- **Проекты:** `PLC_V3.gxw` (ПЛК), `HMI_V3.prj` (панель)

## Файлы

| Путь | Назначение |
|------|------------|
| `ПО/IO.csv` | привязки входов/выходов (X / Y / D / R) — источник истины |
| `ПО/GVL.csv` | глобальные переменные и константы |
| `ПО/*.iecst` | код ST: `PRG_INIT`, `PRG_MAIN`, `PRG_PROCESS` |
| `ПО/*.csv` | переменные программ — импорт в Label Editor |
| `ПО/плк.txt` | карта адресов модулей (для сверки) |
| `Modbus.md` | карта регистров для удалённого подключения по Modbus |
| `img/` | иконки HMI (вентилятор — 4 состояния, клапан — 2) |
| `Архив/` | старые версии |

CSV — UTF-16 LE с BOM, разделитель Tab, все ячейки в кавычках. Иначе GX Works 2
не импортирует.

## Программы

| POU | Назначение |
|-----|------------|
| `PRG_INIT` | инициализация ПИД и аварий (запуск по M8002) |
| `PRG_MAIN` | автомат сушки, ПИД температуры и влажности |
| `PRG_PROCESS` | ввод и масштабирование, аварии, управление ПЧ, данные для HMI |

## Программа сушки

До 5 этапов (`grSteps[0..4]`), каждый — подъём + выдержка. Время — в минутах.

| Шаг | Состояние |
|-----|-----------|
| 0 / 1 / 2 | Init / Reset / Idle |
| 10 | выбор этапа |
| 20 | подъём |
| 30 | выдержка |
| 40 | пауза (снят ПУСК / блокирующая авария) |
| 50 | завершено |

## Ручной режим

Ручной режим активен, когда автомат находится в шаге **2 (Idle)** — процесс не идёт.
Признак для панели: `gxManualMode` (M441).

- Вентиляторы ПЧ1-ПЧ14: команда пуска — `gxVFD1`...`gxVFD14` (M420-M433),
  скорость — `giVFD1Speed`...`giVFD14Speed` (D1076-D1089, 0-500 = 0.0-50.0 Гц).
  ПЧ запускается при `gxVFDn = TRUE` и скорости > 0 (при отсутствии аварии ПЧ).
- ПЧ вентиляции/увлажнения (ПЧ ВЕНТ): команда пуска — `gxVFDVent` (M443),
  скорость — `giVFDVentSpeed` (D1092, 0-500 = 0.0-50.0 Гц). В процессе — ПИД влажности.
- Клапаны: положение — `giValve1Pos`, `giValve2Pos` (D1090-D1091, 0-100%),
  масштабируется в 0-4090 на `AO_Valve1` / `AO_Valve2`.
- При старте процесса (переход Idle → выбор этапа) все ручные команды и уставки
  сбрасываются в 0. Кнопка СБРОС (`gxReset`) сбрасывает их тоже.
- В процессе вентиляторы работают автоматически на подъёме и выдержке
  (`gxFansRun`, M442) на скорости этапа `giCSVFDSpeed`.

## Аварии

AlarmManager, 24 аварии (`c_AM_ALARMS_NUM = 23`):

| № | Авария |
|---|--------|
| 0-14 | ошибка ПЧ1-ПЧ14 и ПЧ вентиляции |
| 15-21 | обрыв датчиков температуры (воздух 1-4, продукт 1-3) |
| 22-23 | потеря обратной связи задвижки 1 / 2 |

Состояния упакованы в биты `M3000+N`. Любая авария — `gxHasAlarm` (M439).

## Регистры D (HMI)

| Адрес | Метка | Назначение |
|-------|-------|------------|
| D1000-D1007 | `giCS_*` | этап: номер, истёкшее и общее время, уставки, скорость ПЧ |
| D1008 | `giProbeType` | датчик температуры: 0 — среднее, 1 / 2 — датчик 1 / 2 |
| D1009-D1014 | `giPID_T_*`, `giPID_H_*` | ПИД: уставка, текущее значение, выход |
| D1015-D1016 | `giStart_T`, `giStart_H` | начальные значения этапа |
| D1017-D1018 | `giRaiseET`, `giHoldET` | остаток подъёма / выдержки, % |
| D1020-D1034 | `giVFD#State` | состояние ПЧ (код ниже) |
| D1035 | `giCS_NumDisplay` | номер этапа для HMI (0 — процесс не идёт) |
| D1036-D1037 | `giRaiseMinLeft`, `giHoldMinLeft` | остаток подъёма / выдержки, мин |
| D1050-D1074 | `fT1`...`fFlow` | тренды REAL: температуры, давление, влажность, поток |
| D1076-D1089 | `giVFD1Speed`...`giVFD14Speed` | ручная уставка скорости ПЧ1-14, 0-500 (0.0-50.0 Гц) |
| D1090-D1091 | `giValve1Pos`, `giValve2Pos` | ручное положение клапанов 1 / 2, 0-100% |
| D1092 | `giVFDVentSpeed` | ручная уставка скорости ПЧ ВЕНТ, 0-500 (0.0-50.0 Гц) |

Код состояния ПЧ: 0 — не активирован, 1 — не работает, 2 — работает, 3 — ошибка.

## Метки M (управление)

| Адрес | Метка | Назначение |
|-------|-------|------------|
| M400 | `gxReset` | сброс программы |
| M401 | `gxStart` | пуск / продолжение (FALSE — пауза) |
| M402-M405 | `gxPIDAN*` | автонастройка ПИД (вкл., режим) |
| M406 | `gxDone` | процесс завершён |
| M420-M433 | `gxVFD1`...`gxVFD14` | ручной пуск ПЧ1-14 (только Idle) |
| M434 | `gxAlarmReset` | сброс аварий |
| M435 | `gxProgress` | процесс выполняется |
| M436 | `gxPause` | пауза |
| M437-M438 | `gxValve1Work`, `gxValve2Work` | клапан 1 / 2 в работе |
| M439 | `gxHasAlarm` | есть любая авария |
| M440 | `gxNextStep` | «Следующий этап» — завершить текущий этап |
| M441 | `gxManualMode` | ручной режим (шаг Idle = 2) |
| M442 | `gxFansRun` | процесс: вентиляторы работают (подъём / выдержка) |
| M443 | `gxVFDVent` | ручной пуск ПЧ ВЕНТ (только Idle) |

## Заметки

- Шкала положения клапанов: в коде используется 0-4090 (`R522 := 4090`, обратная связь 0-4090),
  в библиотеке/описании упоминается 0-4000. Расхождение зафиксировано, не менялось.
- Порядок программ `PRG_INIT` → `PRG_MAIN` → `PRG_PROCESS`: `gxManualMode` / `gxFansRun`
  вычисляются в `PRG_MAIN` и читаются в `PRG_PROCESS` (задержка в один скан допустима).

- `grSteps` и `garstStepHelper` не привязаны к устройству — задать вручную в GX Works 2.
- Кнопка «Следующий этап» работает в шагах 20 / 30 (подъём / выдержка).
