# Проект: Автоматизация камеры овощехранилища (ПЛК Coolmay L02)

## Что это за проект

Разработка программы ПЛК для автоматизации камеры хранения картофеля (520–720 т),
г. Алма-Ата. Один проект заливается в 10 однотипных шкафов ШУК.260726
(10 камер). Платформа: **COOLMAY-L02** (совместим с FX3G), программирование —
**GX Works 2, IEC 61131-3 Structured Text (ST)**. HMI: **COOLMAY-TK8100**.

Система управляет: 6 напорными + 4 разгонными вентиляторами, 6 клапанами Belimo
(приток×2, сброс×2, рециркуляция×2), подогревом заслонок (4 ТЭН), блокировкой
охладителя, световой колонной (🔴/🟢). Режимы: Выключено / Авто
(рециркуляция + периодическая аспирация по таймеру) / Продувка (ручной).
28 тревог, мониторинг на HMI, PUSH-уведомления (интеграция вне ПЛК).

## Технический контекст (кратко)

**Адресация (итог):**
- DI: X00=Авто, X01=Продувка, X02=реле контроля фаз, X06–X13=обратная связь
  напорных вент. 1–6, X20=охладитель в работе, X21=увлажнитель работает,
  X24–X31=концевики клапанов (приток1,2 / сброс1,2 / рециркуляция1,2),
  X32–X37=реле давления 1–6. Разгонные вентиляторы (220 В, без защиты)
  обратной связи не имеют.
- DO: Y00=остановить холод (**1 = запрет охлаждения, 0 = разрешение**;
  при обесточивании ПЛК холод не блокируется), Y02–Y05=разгонные вент. 1–4,
  Y06–Y13=напорные вент. 1–6, Y20–Y23=подогрев заслонок, Y24–Y31=открыть клапаны,
  Y32=колонна зелёный, Y33=колонна красный.
- AI: D8030=t улицы (Pt100, host, контроль обрыва есть), D8032=t ПВТ110 (4-20 мА),
  D8033=влажность ПВТ110 (4-20 мА) — обрыв ≥ 32720, только host;
  R23700–R23703=щупы продукта Pt100 — модуль L02-RTD выдаёт готовую температуру,
  контроля обрыва на модуле нет (детекция по значению ≤ −190 °C).

**Библиотеки:** TimeControl V2 (обязательна: TCO_TICKER_50, 50 мс), AlarmManager
V212 (задержки в 50 мс; хранилище AM_ALARMS/AM_EVENTS объявляет приложение; лимиты D +1400, M +2000 в макс. конфигурации), Modbus V1.5, Utils V3.

**Тревоги (28, c_AM_ALARMS_NUM=27):** реле фаз (0с, X02), клапаны не открылись 6×60с,
нет потока 6×30с, пускатель напорного не замкнулся 6×3с (защёлка, ручной сброс),
обрыв Pt100 5×3с (≤ −190 °C), обрыв 4-20мА 2×3с (≥ 32720, только host),
t продукта выше макс (5с), влажность ниже мин (5с).

**Уточнённые решения (ТЗ v1.1):** увлажнитель — один вход X21 (работает/нет);
в режиме «Продувка» ПЛК сам ставит клапаны (рециркуляция открыта, приток/сброс
закрыты), вентиляторы — вручную; Y00 = 1 только во время аспирации.

## Правила работы

1. **Сначала читай `plnas/план_разработки.md`** — это источник истины по этапам,
   структуре POUs, карте регистров и распределению тревог. При изменении плана —
   обновляй файл.
2. Код — в `ПЛК/src/*.st`, один файл на POU (имена и назначение — в плане §7).
   Программа пишется на ST для GX Works 2 (IEC). Все изменения — с комментариями
   на русском.
3. Известные расхождения ТЗ↔карта адресов и открытые вопросы — в плане §4 и §9.
   Не «чинить» их молча: фиксируй в `plnas/вопросы_заказчику.md`.
4. Не выходить за рамки ТЗ без согласования. Упрощение допускается только если
   оно не меняет функциональность по ТЗ.
5. После каждого завершённого этапа — коммит в git (сообщения на русском).
6. При работе с библиотеками сверяться с их документацией в `Ссылки/` — сигнатуры
   ФБ, единицы задержек (50 мс), требования к лимитам устройств.
